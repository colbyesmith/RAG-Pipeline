PDF RAG workspace

Ask questions in natural language—answers are grounded in your uploaded PDFs via hybrid search (BM25 + dense embeddings) and optional reranking, then a Mistral chat model. Responses are plain text (no citation tables in the UI). For scanned/image-only PDFs you’ll need text extracted elsewhere first.

Developer? Open /docs for the REST API · ingest POST /ingest · query POST /query

How to use

  1. Add PDFs — text-based files work best (native text layer).
  2. Ingest — chunks text, calls Mistral embeddings, builds the index in memory.
  3. Ask — type a question; retrieval runs, then the model answers from context.

Heads-up: data lives in RAM until you restart the server. Set MISTRAL_API_KEY in .env for live API calls. If you see “insufficient evidence,” try a clearer question or add more relevant PDFs.
